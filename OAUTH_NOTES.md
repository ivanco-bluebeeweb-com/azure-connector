# Azure Connector — заметка по аутентификации (OAuth)

Дата анализа: 2026-08-31

## Коротко: OAuth ЕСТЬ, но серверный (client credentials) — без браузера

Коннектор работает по **OAuth2 Client Credentials Grant** — это настоящий
OAuth, но машина-к-машине: без окна браузера и без кнопки «войти через
Microsoft». Токен запрашивается напрямую у
`login.microsoftonline.com/{tenant_id}/oauth2/v2.0/token` и кэшируется
в памяти до истечения (см. `azure_client.py`, `_get_access_token`).

## Как устроено подключение сейчас

Пользователь вводит в панели Imperal три значения:

1. **Tenant ID** — каталог Entra ID;
2. **Client ID + Client Secret** — от App Registration;
3. **Subscription ID** — подписка Azure, которой управляем.

## Что автоматизировано, а что — руками

| Этап | Как делается |
|---|---|
| Создание App Registration | **РУКАМИ** — Azure Portal → Entra ID → App registrations → New registration |
| Выпуск Client Secret | **РУКАМИ** — Certificates & secrets → New client secret (у секрета есть срок жизни — за просроченным коннектор явно подскажет, где его перевыпустить) |
| Назначение прав на подписку | **РУКАМИ** — Subscription → Access control (IAM) → Add role assignment (минимум Reader; для старт/стоп ВМ — Contributor) |
| Получение и обновление токена | **АВТОМАТИЧЕСКИ** — коннектор сам запрашивает и кэширует токен |

## Почему нет браузерного OAuth (Authorization Code)

Сознательное архитектурное решение, как и в Salesforce: коннектору нужен
доступ 24/7 от имени сервиса, а не от имени конкретного человека с его
сессией. Делегированный доступ (Delegated permissions через браузер)
привязал бы управление подпиской к чьему-то личному логину и ломался бы
при смене пароля/увольнении сотрудника. Application permissions +
client credentials — правильная модель для фоновой автоматизации, и это же
рекомендует сам Microsoft для daemon-сценариев.

## Следствие для тестирования

Полный тест (ВМ, Storage, SQL, функции, метрики, затраты) требует, чтобы
пользователь создал App Registration в своём тенанте и передал три значения
в панель. Автоматически с нашей стороны сделать это нельзя — Azure не выдаёт
приложения «по ссылке», это политика безопасности Microsoft.
